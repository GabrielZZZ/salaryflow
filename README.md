## 薪流是什么

薪流把你的月薪拆成日薪、时薪、分钟薪和秒薪，让"今天的班"变成一个每秒都在跳动的数字。它不理财、不记账，只回答一个问题：**此刻的时间，值多少钱？**

打开 App 或瞥一眼桌面小组件，你会看到今天已经赚了多少、离下班还有多久、这周已经落袋多少。到了你设置的休息日，它会安静下来，只提醒你距离下一次上班还有多久。

## 功能

| 模块 | 能做什么 |
| --- | --- |
| 💰 实时薪资 | 按秒累计今日收入；下班自动定格，休息日切换为本周/本月累计 |
| ⏱️ 薪资速率 | 日薪 / 时薪 / 分钟薪 / 秒薪自动换算 |
| 📅 工作日与休息日 | 周一至周日任意勾选；休息日不计薪，显示专属的本周/本月累计与上班倒计时 |
| 🧾 五险一金与个税 | 可选拆分：把总包实时拆成 五险一金 / 个税 两条线，看得见扣在了哪 |
| 🎯 心愿清单 | 把物品价格换算成连续工时与实际工作日 |
| 🐟 摸鱼计时 | 开始/结束计时，算出这段"带薪摸鱼"值了多少钱 |
| ⚡ 意外收支 | 记录计划外的收入与支出 |
| 📦 我的好物 | 记录已拥有的物品，观察持有时间越长、每小时成本越低 |
| 📱 桌面小组件 | 2×2 / 4×2 / 4×3 三种尺寸，秒级跳动，锁屏外常驻 |

## 计薪口径：总包与分解

大数字始终是**总包口径**——公司为你的时间支付的价格。

开启「拆分五险一金与个税」后（默认开启），今日金额下方会实时显示：

```
¥842.90                    ← 总包口径
到手之前的扣减：
五险一金 ¥1,924.97 · 个税 ¥710.81（今日累计，随班次实时累计）
```

估算口径（设置中可调公积金比例与专项附加扣除）：

- 社保个人合计 10.5%（养老 8% + 医疗 2% + 失业 0.5%，固定档估算）
- 住房公积金按配置比例（默认 12%）
- 个税按月度税率表速算（起征点 5000 + 专项附加扣除可配）

以上为估算值，实际以工资条为准。

## 工作日与休息日

设置页提供周一至周日七格选择器，勾选哪几天就在哪几天计薪：

- **工作日**：班次内金额逐秒跳动，午休（可选计薪）自动暂停，下班定格
- **休息日**：不计薪，大数字切换为「本周已经赚了」，并显示逐秒的上班倒计时

## 桌面小组件

| 尺寸 | 内容 |
| --- | --- |
| 2×2 | 标签 + 金额 + 倒计时/秒薪 + 进度条 |
| 4×2 | 2×2 的基础上增加班次时间行与元信息行 |
| 4×3 | 完整卡片：金额、秒薪、时薪数据条、人生时间换算、班次进度、倒计时 |

- 五种状态自适应：实时中 / 午休中 / 上班前 / 已收工 / 休息日
- 倒计时由桌面启动器驱动，App 被划掉后依然逐秒走动
- 长按桌面空白处 → 小组件 → 薪流，选择尺寸添加

## 安装

1. 从 [Releases](../../releases) 下载最新的 `salaryflow-vX.Y.Z.apk`
2. 安装（首次安装如曾装过其他签名的版本，需先卸载）
3. 打开 App，填入薪资、班次与工作日，保存即可——桌面小组件会同步这些设置

要求 Android 7.0（API 24）及以上。

## 从源码构建

要求 Node.js 20+ 与 Android SDK。

```bash
# Web
npm ci
npm run dev:web        # 本地开发 http://localhost:5173
npm run build          # 产出 apps/web/dist

# Android（Capacitor 生成工程 + 模板覆盖）
cd apps/web
npx cap add android
npx cap sync android
node native/android/prepare-android.mjs
cd android
./gradlew assembleDebug      # 产出 app/build/outputs/apk/debug/app-debug.apk
```

签名、版本号与发布流程见 [`docs/MOBILE.md`](docs/MOBILE.md)，小组件架构见 [`docs/WIDGETS.md`](docs/WIDGETS.md)。

## 隐私

- **local-first**：薪资配置、心愿、摸鱼记录、收支与物品数据全部保存在设备本地
- 无账号、无登录、无遥测、无任何第三方服务依赖
- Web 端数据存于浏览器 localStorage；Android 端存于应用私有目录
- 不同设备之间不自动同步
